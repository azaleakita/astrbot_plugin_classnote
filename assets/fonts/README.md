# Bundled Chinese font

`NotoSansSC-Bold.ttf` is a static weight-700 instance of Google's Noto Sans SC variable font, generated using fontTools. It includes the upstream Chinese character repertoire; no online font service or host-installed font is required.

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
